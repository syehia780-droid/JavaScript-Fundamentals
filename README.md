# JavaScript Fundamentals Assignment

## 📌 About the Project
This repository contains practical JavaScript exercises completed as part of a training assignment. It covers fundamental JavaScript concepts and hands-on coding practice.

## 🛠️ Topics Covered
- Variables and Data Types
- Type Conversion and Operators
- Conditional Statements and Loops
- Arrays and Array Methods
- Functions and Recursion
- Objects and Object Methods
- Error Handling (`try`, `catch`, `finally`)
- Date and Time Manipulation
- Browser APIs (`window`, `navigator`, `location`, and `history`)
- Timers using `setTimeout` and `setInterval`
- Promises, Microtasks, and the JavaScript Event Loop

## 🎯 Learning Objectives
- Practice JavaScript fundamentals through coding exercises.
- Improve problem-solving and logical thinking.
- Understand browser-related JavaScript features and asynchronous execution.

## 💻 Technologies Used
- JavaScript (ES6+)
- Web Browser Developer Tools

## 📚 Project Type
Educational Assignment / Practical Training
